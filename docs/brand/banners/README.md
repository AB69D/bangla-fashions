# Hero banners

Generated by `generate-banners.py` (needs Pillow). Output is 2000x1000.

The storefront crops the hero three different ways, so all content has to sit
inside a safe box of **x 210-1790, y 150-850**:

| viewport | class | crop |
|---|---|---|
| phone | `aspect-[16/10]` | 200px off each side |
| tablet | `sm:aspect-[2/1]` | none |
| desktop | `lg:h-[62vh]` | up to ~145px off top and bottom |

Verified rather than assumed: the live page reports container aspect 1.6 against
a 2.0 image with `object-fit: cover`, i.e. 80% of the width visible.
`generate-banners.py` writes `*-crops.png` alongside each banner showing exactly
what each viewport displays — check those before uploading a new one.

Upload via Admin -> Header images.
